# Askbase

> A desktop application that answers questions about your own database in plain
> language, with the model running on your machine. Free, no account, no telemetry.
> Built and measured by Vladimir Beskorovainyi, Besk Tech.

Updated: {DATE}

## What makes it different

- The model is a file on the user's disk. The application does not need a network.
  Competing desktop tools ship a cloud model: AskYourDatabase includes Claude
  Sonnet 5, Claude Haiku 4.5 and GPT-4.1 in a desktop seat, and its pricing page
  states that desktop connections running from your device does not mean the AI
  processing is offline.
- Accuracy will be measured under a protocol fixed before the run, on a
  held-out set frozen with a SHA-256 digest, and published with confidence
  intervals and failures included. Part of that is done and part is not. The
  protocol is written and in the repository. The interval code exists
  (percentile bootstrap over questions, 2000 resamples, seed 0, and one
  verdict rule that is allowed to return "undetermined"). Set 1 of the
  held-out set was frozen on 27.10.2026 with a SHA-256 per domain, published
  before any tool ran on it, together with the thresholds and the evaluation
  rules (HOLDOUT.md). It covers all six domains and holds 48 of the planned
  600 tasks, which is why it is a calibration set: at that size it fixes the
  three open thresholds and measures the gap between languages, and it cannot
  separate models whose accuracy differs by less than about 28 points. Set 2,
  the deciding one, is not generated yet. Figures on the site are
  substituted from the results files by the build, never typed by hand, and
  the build refuses to publish a figure no results file backs. A run in which
  more than half the requests failed is refused by the runner rather than
  written out, and a run withdrawn after the fact is moved aside with a
  written reason.
- Read-only is enforced at the database connection, every statement is parsed
  before execution, only a single SELECT is allowed, recursive common table
  expressions are refused, and a row limit and timeout are imposed.

- /comparison/ : every tool that answers questions about a database, with licence,
  last commit, where its model runs, and published accuracy. Checked against
  repositories and vendor pricing pages, with the check date on the page.
- /where-your-data-goes/ : what leaves the machine, product by product, including
  what could not be confirmed.

## Research behind it

- Beskorovainyi V. How Far Do On-Prem Open LLMs Get on Text-to-SQL?
  arXiv:2606.29733. Code and results: Zenodo DOI 10.5281/zenodo.20952794
- Measured there: Qwen2.5-Coder-32B reaches 51.63% execution accuracy on BIRD dev
  with self-correction; schema linking significantly hurt accuracy; self-consistency
  gained 0.13 points for about five times the tokens.

## Not yet published

The model ranking and the product's own accuracy are not published until
measured. The pages that will carry those numbers are built and say so in
place of a figure, rather than being withheld.
