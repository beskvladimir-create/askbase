# Fonts

Inter, Playfair Display and Space Grotesk, each under the SIL Open Font
License 1.1. The licence text for each is in this directory, as the licence
requires when the fonts are redistributed.

The fonts are served from this site rather than from a font CDN. A CDN request
would tell a third party who opened the page, which would sit badly next to a
product whose claim is that nothing leaves the computer.
