Askbase / Установка
Установка · версия 0.1.1 · macOS, Apple Silicon

Скачайте Askbase и разрешите macOS открыть его в первый раз

Сборка пока не подписана удостоверением разработчика Apple, поэтому macOS откажется её открывать, пока вы не разрешите это один раз. Это два нажатия, и здесь показано, где именно. А заодно объяснено, что это предупреждение на самом деле значит: продукт, который просит отмахнуться от предупреждения безопасности, обязан это объяснить.

Выпуски на GitHub Исходники на GitHub

0.1.1 собран, но ещё не опубликован, а 0.1.0 пользоваться не стоит. Выпуск 0.1.0 не отвечает на вопросы вообще: ответ не доходил до окна из потока, который его считал, поэтому часы шли, а ответ не появлялся. Это дефект приложения, а не вашей базы и не модели, и в 0.1.1 он исправлен. Пока 0.1.1 не появился на странице выпусков, соберите из исходников четырьмя командами ниже, так получится исправленная версия.

Что нужно, чтобы он мог отвечать

Askbase не скачивает модель и не пользуется облачной. Он обращается к модели, которая уже стоит у вас, через локальную петлю, поэтому и работает с выключенной сетью. Поставьте модель через Ollama:

ollama pull hf.co/mradermacher/XiYanSQL-QwenCoder-7B-2504-GGUF:Q4_K_M

Примерно 4,7 ГБ на диске. Первый вопрос после запуска занимает около минуты, пока модель грузится в память, следующие по несколько секунд.

Как открыть в первый раз

  1. Откройте образ и перетащите Askbase в Программы.
  2. Запустите. macOS скажет, что разработчик не может быть проверен, и предложит только кнопку Готово. Так и должно быть.
  3. Откройте Системные настройки → Конфиденциальность и безопасность, промотайте до раздела «Безопасность» и нажмите Всё равно открыть рядом со строкой про Askbase.
  4. Запустите снова и подтвердите. Решение запомнится, больше спрашивать не будут.

Что это предупреждение значит, без прикрас. Оно не означает, что macOS нашла в приложении что-то плохое. Оно означает, что никто не заплатил Apple за поручительство: подпись и нотаризация требуют учётной записи разработчика, а у этой сборки нет ни того, ни другого. Поэтому система не может сказать вам, кто это сделал и что файл не меняли после сборки, и отказывается предполагать.

Относиться к этому с подозрением правильно. Проверяемый ответ такой: исходный код опубликован. Всё, что приложение делает с вашей базой, лежит в репозитории, включая режим только для чтения и правило, отклоняющее любое соединение за пределы этого компьютера. Если верить предупреждению на слово не хочется, соберите приложение сами, это ниже.

Или запустите из исходников, тогда предупреждения не будет вовсе

Четыре команды. Получится то же самое приложение, собранное на вашей машине, то есть доверять нечему и разрешать нечего.

git clone https://github.com/beskvladimir-create/askbase
cd askbase/desktop
uv venv && uv pip install PySide6 sqlglot
.venv/bin/python -m askbase

Так же проверяется и само обещание, а не принимается на веру:

.venv/bin/python -m askbase --selftest

Приложение пытается выйти наружу и ожидает отказа, пытается достучаться до этого компьютера и ожидает успеха, и возвращает ноль, только если выполнилось и то, и другое.

То же самое из терминала

Для тех, кому нужен запрос, а не ответ. Это обёртка над тем же движком, что и у окна, то есть соединение только на чтение, проверка запроса и границы там одни и те же. Qt ей не нужен, поэтому она работает там, куда приложение не собирается. В образ .dmg она пока не входит, ставится из исходников:

git clone https://github.com/beskvladimir-create/askbase
cd askbase/desktop
uv venv && uv pip install -e .

askbase "сколько новых клиентов пришло из каждого региона в сентябре" --db sales.sqlite
askbase "десять клиентов с наибольшей выручкой" --db sales.sqlite --sql-only
echo "заказы без оплаты дольше 30 дней" | askbase --db sales.sqlite --json | jq .sql

Коды возврата это договор, по ним скрипт различает случаи: 0 ответ получен, 1 ошибка вызова, либо модель не установлена или не отвечает, 2 из вопроса не вышло запроса, который прошёл бы проверку на чтение, 3 база отклонила запрос, не открылась или запрос был остановлен по таймауту. --csv пишет весь результат, а не показанные строки, --no-journal не заносит вопрос в локальный журнал.

Когда предупреждение исчезнет

Когда сборка будет подписана и нотаризована, а для этого нужна учётная запись разработчика Apple. До тех пор здесь будет написано именно так, а не сделан вид, что этого шага нет. Сборок для Intel и для Windows тоже пока нет: приложение написано переносимым, но каждой платформе нужна своя упаковка и своя подпись.
